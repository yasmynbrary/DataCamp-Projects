# Investing Netflix Movies


## About the Project
In this project, I explored Netflix data to learn more about movies released in the 1990s.

I used Python and Pandas to analyze movie durations and find the number of short action movies released during this decade.

## Questions
- What was the most common movie duration in the 1990s?
- How many action movies were shorter than 90 minutes?

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Files
- `netflix_data.csv`: The dataset used in the project.
- `notebook.ipynb`: The notebook containing the analysis.

## Goal
The goal of this project was to practice data analysis and learn how to explore a dataset and find useful information from it.
